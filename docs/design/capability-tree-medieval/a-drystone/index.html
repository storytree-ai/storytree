The library

Mock A: drystone walls and arched stone gates

The capability tree drawn as one island of The library: each capability a field fenced by drystone walls, sized by its lines of code and coloured by its health. Cobbled lanes are the links between capabilities, and where a lane crosses a wall there is an arched stone gate with its wooden door open.

Everything on the island is measured (data.json, 2026-11-02). One open increment names one of these capabilities today, so the one wrench is real: it hangs on Cloud connection's gate.

Click a field for its description and contracts, a lane or gate for the contracts it carries, the wrench for the arcs that want it.
