    About: Every record has a declared type with fixed fields, and a badly filled-in record is refused, naming the problem field. Every record is stamped with the schema version it was written on, so a later change to a type is handled deliberately rather than silently misread: an older record is upgraded automatically, step by step, and stored upgraded the next time it is written, because every user's library is their own database and nobody else can repair it.
    Decisions: founded on "3 · Data schema: founding book (ADR-0621 D1; ADR-0636 a1)" (decision_5b9ef03b8a42, ADR-0701); also "A process's schedule is stored as its words, read by one parser; its last run is an activity-log line" (decision_82ad2af0876b, ADR-1105).
