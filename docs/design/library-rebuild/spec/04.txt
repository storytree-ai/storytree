  Capability "4 · Work model" (capability_dd486ffa5b02): reported not checked, verified passing; healthy; nobody holds it
    About: Holds each project's plan: stories (what a user can do), the capabilities that make each work, and contracts (single testable promises), and refuses broken structure. Stories belong to the project; the arcs that grow them, and may list them, are Work in flight's to write, and the plan's tree reads them. Only an import maps a story, and an explored capability names the imported files it covers. A session holding an increment makes its plan edits pending changes until it lands. (ADR-0966, ADR-0993, ADR-1242)
