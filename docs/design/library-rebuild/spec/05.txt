    About: Says whether each story, capability and contract works, keeping what the agent reported apart from what storytree saw for itself. Each column reads passing, failing or not-checked; a missing entry reads not-checked, never passing. A capability's word is proposed while its flag is on; once off, healthy when every contract is verified passing, unhealthy when any is verified failing, untested otherwise. Only the verified column counts: the agent's report never makes a capability healthy. (ADR-0744)
