Story "The library" (story_754e87e7d531): reported not checked, verified passing
  Capability "14 · Ranked search" (capability_556e276756c9): reported not checked, verified passing; healthy; nobody holds it
    About: A library search ranks the live artifacts by how close their meaning is to the question, using an embedding model run on this computer. It needs no LLM, paid API or extra service, as the owner directed. An artifact written or edited is embedded again before the next search ranks it; with no model to hand, the search falls back to word matches and says why. ARM64 PE headers are inspected, with ARM64 execution awaiting a native Windows acceptance run. (ADR-1115; 0.2's ADR-0664)
    Decisions: founded on "Library search ranks by meaning with a local embedding model (Hindsight parked)" (decision_59f6c07aedc4, ADR-0732); also "Ranked search runs bge-small in process, keeps vectors by chunk hash in the project's Postgres, and falls back to words" (decision_153f390ff901, ADR-0733), "Library search embeds with Snowflake's arctic-embed-s, switched without a measurement" (decision_e9a49b4882aa, ADR-1115).
