The to-do app is built. Double-click `index.html` and it opens in your browser with the TodoMVC look. All 13 of my own tests pass in headless Edge. I haven't run the official TodoMVC test suite against it, because this computer has no Node.js and that suite needs it.

**What works (following the spec):**
- **Adding:** type a to-do and press Enter. Spaces at either end are trimmed and blank entries are ignored. The list and footer stay hidden until there's at least one to-do.
- **Counter:** shows "1 item left" or "N items left".
- **Completing:** tick a to-do's checkbox, or use the "mark all" toggle, which also shows as ticked when everything is done. "Clear completed" only appears when something is completed.
- **Deleting:** hover a to-do and click the .
- **Editing:** double-click a to-do. Enter or clicking away saves it, an empty edit deletes it, and Escape cancels.
- **Filters:** All, Active and Completed, using the `#/`, `#/active` and `#/completed` addresses. The list updates straight away when something changes under a filter.
- **Saving:** to-dos are kept in your browser's storage (under `todos-vanillajs`), so they're still there after a reload.

**How it's made:**
- `index.html` is the official template markup with the example to-dos removed.
- `css/base.css` and `css/index.css` are the official TodoMVC stylesheets. I downloaded them into the folder so nothing needs installing.
- `js/app.js` is the app itself, in plain JavaScript.

**Things to know:**
- **The official tests:** the official suite looks for elements like `.new-todo`, `.todo-list li` and `.toggle-all`. I kept those exactly as the template has them, so it should find everything.
- **`base.js` is left out:** the template normally includes this helper script, but it tries to download a file when it starts, which fails when the page is opened straight from disk. The app doesn't need it.
- **Running my tests:** `powershell -ExecutionPolicy Bypass -File test\run.ps1`. Edge prints some `ERROR:chrome` lines while it runs; those are harmless.
