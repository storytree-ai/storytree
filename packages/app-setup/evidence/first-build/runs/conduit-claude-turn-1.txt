## How to open it

In PowerShell, in this folder:

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Then go to **http://localhost:8080/**. Press Ctrl+C to stop it.

Double-clicking `index.html` won't work. Your requirements ask for addresses like `/tag/react` that only work through a server that always sends back the main page. Your computer has no Node or Python, so `serve.ps1` is a small server built into PowerShell, and nothing needs installing.

## What works now
- **Global feed:** shows up to 10 articles per page from `https://api.realworld.show/api`, with author picture, name, date, title, description, tags and the favourite count. A missing picture shows `default-avatar.svg`. Any HTML in an article's text is shown as plain text, not run.
- **Popular tags:** listed in the sidebar. Clicking one goes to `/tag/<tag>`, adds an active tab for that tag and shows only its articles.
- **Pagination:** one link per 10 articles, with the current page marked `active` and the page in the address (`?page=N` or `/tag/<tag>?page=N`). It's hidden when everything fits on one page.
- **Navigation:** the logged-out navbar (conduit, Home, Sign in, Sign up) and the footer. Clicking links and using Back don't reload the page. Pages from later parts, like `/login`, show a "not built yet" placeholder.
