Start your first project
Open your chosen agent in your project folder. After connecting Claude Code or Codex during installation, start a new session there. Storytree does not run the agent for you.
Say yes when asked. The agent checks setup and asks before creating a storytree project. Choose its name. Saying no leaves the folder unconfigured.
Let the connection check finish. Review any approval prompt from your agent for storytree tools, a small check-file edit or a command. Approve the check if you want to continue. Ask the agent to run check_setup again until it reports hooks verified: session start, tool call, file edit and command have reached storytree. Registered hooks alone are not verification.
Give the agent a small piece of work. Your new project appears in the running app. Its forest can start empty; a story and its capabilities appear as the agent plans them, with activity and health as work proceeds.
Add another project

Start a new agent session in a second folder and answer its setup question separately. Only a second yes creates a second project. The app refreshes its project list automatically; use the project picker to return to either forest.
