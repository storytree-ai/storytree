# Session-orchestrator Check step

For the laptop supervisor after this PR merges. Edit the live session-orchestrator role, then run `pnpm build:guidance` and `pnpm gate -- --guidance`. The lane does not edit generated guidance or the live library.

Replace the existing Check step with the following text; the unchanged scoping details remain part of the step. Compare the old text with the live role before applying.

## Old

4. **Check.** `pnpm typecheck` and `pnpm test` pass, and `pnpm check:guidance` passes if you touched agent roles or the notes they stand on. Nothing red or unfinished in the diff. **Tests run only what your change can reach (ADR-0649 D4):** `pnpm test` runs the packages your branch changes plus every package that depends on them, and everything when a change cannot be mapped (a root file, a package.json, the lockfile, `scripts/**`, an unreadable `origin/main`); CI decides the same way. Its first line is the decision (`scope: …`): read it. `pnpm test -- --scope` prints the decision and runs nothing, `--full` runs everything, `--rerun-failed` reruns only what failed. Every unit runs and the run ends in a PASS / FAIL / NOT RUN table; NOT RUN is unverified, never passed. A narrow green is not a full proof, which is also why story code must stay in its own package: a thin frame keeps the dependents small. Fan-out: delegate searches and sweeps whose raw output you do not need to a subagent that returns a cited digest, so your own context stays sharp; drive at most one parallel lane in-thread, and fan genuinely independent lanes out.
